# Лабораторные работы по курсу «Фреймворки ИИ»

**Земсков Павел · группа M8O-401Б · 2026**

Пять алгоритмов для классификации и регрессии. В каждой работе — базовая модель sklearn, проверка способов улучшения, собственная реализация и сравнение результатов. Весь код находится в ноутбуках, ячейки снабжены комментариями.

## Датасеты

| Задача | Датасет | Что предсказываем |
|---|---|---|
| Классификация | [Ames Housing](https://www.kaggle.com/datasets/shashanknecrothapa/ames-housing-dataset), 2 930 домов | Отдельно стоящий односемейный дом или другой тип жилья |
| Регрессия | [Auction Verification](https://archive.ics.uci.edu/dataset/713/auction+verification), 2 043 запроса | Время проверки возможного исхода аукциона в секундах |

## Ноутбуки

1. [KNN](notebooks/01_knn.ipynb) — выбор данных, метрик и числа соседей.
2. [Логистическая и линейная регрессия](notebooks/02_linear.ipynb) — балансировка классов и регуляризация.
3. [Решающее дерево](notebooks/03_tree.ipynb) — глубина дерева и размер листа.
4. [Случайный лес](notebooks/04_forest.ipynb) — ансамбль из 48 деревьев.
5. [Градиентный бустинг](notebooks/05_boosting.ipynb) — число деревьев и их глубина.
6. [Итоговое сравнение](notebooks/06_summary.ipynb) — таблицы, графики и выводы.

Данные лежат в `data/`, таблицы с метриками — в `results/`.

## Запуск

В терминале из корня проекта:

```bash
python3.13 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python download_data.py
python -m jupyterlab
```

Откройте `notebooks/`, выполните работы 1–5 командой **Run → Run All Cells**, затем итоговый ноутбук. Сохранённые результаты уже есть в файлах.
